# 独立项目运行验证

验证日期：2026-10-30。数值记录见 [validation.json](validation.json)。

## 验证方式

将 `reproduce_it2fuzzy.py` 单独复制到临时目录，清除 `PYTHONPATH`，以 Python 的 `-I` 隔离模式运行两种模型。目录内没有上级工程的模块、配置或论文PDF。验证使用已安装依赖的Python解释器，未包含新建环境和重新安装依赖的检查。

环境：Python 3.13.3、NumPy 2.4.3、SciPy 1.18.1、Matplotlib 3.10.8。三个直接依赖的版本记录在 [requirements-lock.txt](../requirements-lock.txt)。

```bash
python -I reproduce_it2fuzzy.py
python -I reproduce_it2fuzzy.py --model paper_a53
```

两组均使用默认参数：20秒采集、400个积分窗口、50组随机控制增益、100秒蒙特卡洛时域、种子2026。
